These files were generated for use in a introductory level groundwater modeling course.

The files in this folder are for MODFLOW Example1 for the 2026 Arizona Hydrological Society (AHS) Introduction to Building and Running Groundwater Models Workshop.

One way to start the model run is to just double click on the Windows command-line file "_RunMe_MODFLOW.bat".

The program file for MODFLOW must be in the same folder or in a location that Windows will access through system variables.

The files are the input files for a MODFLOW 2005 Model which can be run in these versions of MODFLOW:
 - MODFLOW-2005
 - MODFLOW-NWT
 - MODFLOW One Water
 - MODFLOW USG

These files were most recently updated in August of 2026.

All files generated by Justin Allen Clark using flopy, the python package for MODFLOW, and manual changes.
