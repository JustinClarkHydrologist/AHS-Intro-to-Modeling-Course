These files were generated for use in a introductory level groundwater modeling course.

The files in this folder are for MODFLOW Example1 for the 2025 Arizona Hydrological Society (AHS) Introduction to Building and Running Groundwater Models Workshop.

The files are the input files for a MODFLOW 2005 Model which can be run in these versions of MODFLOW:
 - MODFLOW-2005
 - MODFLOW-NWT
 - MODFLOW One Water

These files were most recently updated in September of 2025.

All files generated by Justin Allen Clark using flopy, the python package for MODFLOW.
