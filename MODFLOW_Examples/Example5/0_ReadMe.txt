This is the 100-year projection groundwater model for Phoenix AMA.
This model represents the time period 2023 to 2122.
This model is developed by the Arizona Department of Water Resources (ADWR).
This model was developed using the U.S. Geological Survey's code MODFLOW-NWT.
MODFLOW-NWT.exe is included in the delivery.
This delivery only contains MODFLOW-NWT input packages due to the large size of the output files.

This model uses U.S. feet as the length unit and day as time unit.
The coordinate system of the model grid is UTM12N in U.S. feet.
The lower-left corner of the model grid is (977817.76541, 11989614.88189), without grid rotation.

You can run the model to get the outputs.
To run the model, open a WINDOWS console, change directory (folder) to the folder that contains the model files,
input MODFLOW-NWT_64 phx_ama_proj.nam, and hit RETURN key.
